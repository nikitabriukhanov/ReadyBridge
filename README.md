# ReadyBridge

ReadyBridge is a mobile emergency preparedness application built with React Native and Expo.

The goal of the app is to help users keep important personal information, trusted contacts, emergency instructions, and critical documents organized in one place and ready when needed.

## Features

- Emergency plan creation
- Trusted contact information
- Important document organization
- Local data storage
- Mobile-friendly form design
- Keyboard-aware scrolling
- Smooth save confirmation animations
- Clean and simple user interface

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage
- Git
- GitHub
